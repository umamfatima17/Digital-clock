# Digital Clock

A simple digital clock application built using Python and Tkinter.

## Features

- Displays the current time in 12-hour format with AM/PM
- Displays the current date
- Updates the time every second
- Simple graphical user interface

## Technologies Used

- Python
- Tkinter
- Time module

## How to Run

Run the following command in the terminal:

```bash
python digital_clock.py
```

## What I Learned

- Creating a GUI with Tkinter
- Using Python's time module
- Updating widgets with the `after()` method
- Working with functions and labels
